# TotalMarket Free Academy

An India-focused, free financial education prototype for TotalMarket.

## Current V1 features
- Responsive homepage and six learning categories
- 12 introductory lessons with quick quizzes
- Search and category filters
- 10-term glossary
- SIP and long-position risk/reward calculators
- No external APIs, tracking scripts, dependencies, or login

## Preview locally
Open `index.html` in a browser. All assets use relative paths.

## Publishing
**Do not publish this branch automatically.** Review content and calculations before release. This is a standalone static prototype. To deploy at `totalmarket.co.in/academy/`, merge its built files into the main website's publishing artifact or configure path routing. A second GitHub Pages site cannot claim the same custom domain path by itself.

## Content quality
The included lessons are introductory examples, not a full accredited course. Review financial explanations against official SEBI, NSE, BSE and AMFI educational material before public release. Calculators are hypothetical and exclude taxes, fees and slippage.
